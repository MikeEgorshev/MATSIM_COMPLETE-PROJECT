# Shamalgan Progress Log

This folder tracks project progress in a public, structured format.

## Scope

- Road network preparation and calibration
- Population generation
- PT bootstrap and PT integration
- Scenario runs and diagnostics
- Open risks and next actions

## Files

- `docs/progress/00_timeline.md`: chronological milestones and decisions
- `docs/progress/01_network.md`: road network status, assumptions, and changes
- `docs/progress/02_population.md`: population generation logic and status
- `docs/progress/03_pt.md`: PT build status, assumptions, and data intake plan
- `docs/progress/04_runs.md`: executed runs and key outcomes
- `docs/progress/05_next_steps.md`: prioritized backlog

## Update Rule

After each major session:
1. Append key decisions to `00_timeline.md`.
2. Update the relevant workstream file (`01-05`).
3. Add new run outcomes to `04_runs.md`.
