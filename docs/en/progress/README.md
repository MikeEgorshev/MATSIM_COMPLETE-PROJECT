# Shamalgan Progress Log

This folder tracks project progress in a public, structured format.

## Scope

- Road network preparation and calibration
- Population generation
- PT bootstrap and PT integration
- Scenario runs and diagnostics
- Open risks and next actions

## Files

- `docs/en/progress/00_timeline.md` (or [RU](../ru/progress/00_timeline.md)): chronological milestones and decisions
- `docs/en/progress/01_network.md`: road network status, assumptions, and changes
- `docs/en/progress/02_population.md`: population generation logic and status
- `docs/en/progress/03_pt.md`: PT build status, assumptions, and data intake plan
- `docs/en/progress/04_runs.md`: executed runs and key outcomes
- `docs/en/progress/05_next_steps.md`: prioritized backlog
- `docs/en/progress/06_gap_checklist_2026-03-04.md`: gap checklist vs MATSim book + matsim-berlin, with prioritized implementation plan

## Update Rule

After each major session:
1. Append key decisions to `00_timeline.md`.
2. Update the relevant workstream file (`01-06`).
3. Add new run outcomes to `04_runs.md`.
