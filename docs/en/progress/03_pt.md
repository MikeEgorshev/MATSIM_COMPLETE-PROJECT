# Public Transport Workstream

## Current Status

- GTFS for Shamalgan/Almaty corridor is still incomplete/unavailable in project inputs.
- Current PT is assumption-based from mapped OSM bus stops.

Generated files:
- `scenarios/shamalgan/network-with-pt.xml`
- `scenarios/shamalgan/transitSchedule.xml`
- `scenarios/shamalgan/transitVehicles.xml`

Assumptions used:
- vehicle speed: `30 km/h`
- dwell time: `60 s`
- headway: `360 s`
- service window: `06:00:00 - 23:00:00`

  - supports both `output_transitSchedule.xml` and `.xml.gz`.

## Data Intake Plan (Next)

When new PT station/line data arrives, ingest in this sequence:
1. Stop locations and IDs
2. Route-stop sequences by direction
3. Service windows and headways (or exact timetable)
4. Mode/type and vehicle assumptions

Then:
1. Replace assumed stop CSV with validated source.
2. Regenerate schedule and vehicles.
3. Re-run PT-enabled scenario and compare mode share/travel-time outputs.
