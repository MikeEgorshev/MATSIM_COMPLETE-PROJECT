# Поток работ: дорожная сеть

## Текущий статус

- Активный файл сети: `scenarios/shamalgan/network.xml`
- Топология QA: в порядке
  - одна связная компонента
  - нет изолированных/тупиковых артефактов
- Длинные связующие линки (>5 км): 2 линка, интерпретируются как межпоселковые.

## Политика полос

- В модели используются полосы на один направленный линк MATSim.
- Применённая политика:
  - городские/местные линки: `1 полоса на линк`
  - линки уровня трассы: `2 полосы на линк`
- Теги полос в OSM по местным классам редки; используются значения по умолчанию.

## Политика скорости/пропускной способности

- Реализовано в:
  - `src/main/java/org/matsim/project/PrepareShamalganNetwork.java`
- Профиль «плохих» дорог использует явные целевые свободные скорости:
  - местные `20 км/ч`
  - коллекторы `30 км/ч`
  - магистрали `45 км/ч`
  - трассы `70 км/ч`
