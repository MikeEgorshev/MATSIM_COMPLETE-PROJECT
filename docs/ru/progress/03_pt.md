# Поток работ: общественный транспорт (ОТ)

## Текущий статус

- GTFS по коридору Шамалган/Алматы по-прежнему отсутствует или неполный во входных данных проекта.
- Текущий ОТ строится по допущениям на основе остановок OSM.

Генерируемые файлы:
- `scenarios/shamalgan/network-with-pt.xml`
- `scenarios/shamalgan/transitSchedule.xml`
- `scenarios/shamalgan/transitVehicles.xml`

Используемые допущения:
- скорость ТС: `30 км/ч`
- время стоянки: `60 с`
- интервал: `360 с`
- окно обслуживания: `06:00:00 - 23:00:00`

## Реализованные технические исправления

- Исправлена устойчивость запуска с ОТ при отсутствующих координатах активностей до симуляции.
- Исправлен дашборд SimWrapper для ОТ по шаблону файла расписания:
  - поддерживаются и `output_transitSchedule.xml`, и `.xml.gz`.

## План приёма данных (далее)

При появлении данных по остановкам/линиям ОТ принимать в таком порядке:
1. Местоположения и ID остановок
2. Последовательности остановок по маршрутам и направлениям
3. Окна обслуживания и интервалы (или точное расписание)
4. Режим/тип ТС и допущения по подвижному составу

Затем:
1. Заменить предполагаемый CSV остановок на проверенный источник.
2. Перегенерировать расписание и транспорт.
3. Перезапустить сценарий с ОТ и сравнить доли режимов и время в пути.

## Поиск источников (2026-02-25)

Проверены возможности 2GIS:
- Документация 2GIS Pro по наборам остановок ОТ:
  - https://docs.2gis.com/en/pro/data/built-in/stops
- Страницы API 2GIS:
  - https://api.2gis.kz/en
  - https://docs-new.2gis.com/en/api/navigation/routing/overview

Вывод:
- 2GIS поддерживает информацию по остановкам и маршрутам.
- Прямой массовый экспорт/доступ по API для Казахстана может требовать коммерческого доступа и уточнения в поддержке 2GIS.

Действие:
- При наличии доступа/экспорта — загрузить данные.
- Иначе сохранять PT bootstrap на основе OSM до появления подтверждённого источника.

## Адаптация номеров маршрутов по подсказкам (2026-02-25)

Наблюдаемые в Шамалгане номера маршрутов (по данным пользователя):
- `6`
- `11`
- `213`
- `256`

В сценарий внесено временное соответствие на основе существующей геометрии коридора из OSM:
- Добавлены линии:
  - `line_6`
  - `line_11`
  - `line_213`
  - `line_256`
- У каждой линии два направления:
  - `route_<id>_inbound`
  - `route_<id>_outbound`

Текущие предполагаемые интервалы:
- маршрут `6`: 10 мин
- маршрут `11`: 12 мин
- маршрут `213`: 20 мин
- маршрут `256`: 20 мин

Окно обслуживания:
- с `06:00:00` до `23:00:00`

Важно:
- Это временное соответствие (номера привязаны к текущей предполагаемой геометрии).
- Нужно заменить при появлении проверенных последовательностей остановок/расписаний.

Инструмент:
- `tools/apply_pt_route_numbers.py`

Проверенные ссылки 2GIS:
- Страница остановки с маршрутами `11`, `213`:
  - https://2gis.kz/almaty/geo/70030076132477299
- Пример страницы маршрута `256`:
  - https://2gis.kz/almaty/route/70000001032810931

Примечание:
- Ссылки подтверждают наличие маршрутов, но не дают полного экспорта в формате GTFS для прямой загрузки.
