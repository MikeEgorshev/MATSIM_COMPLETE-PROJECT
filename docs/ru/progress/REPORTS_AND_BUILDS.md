## Сборка производных форматов

### PDF

- **Скрипт:** `tools/md_to_pdf.py`
- **Зависимости:** `fpdf2`, `markdown`; шрифты Arial/Consolas из `C:/Windows/Fonts`.
- **Команды (из корня проекта):**
  - `python tools/md_to_pdf.py` → **`docs/ru/progress/10_final_report_shamalgan.pdf`**
  - `python tools/md_to_pdf.py concepts` → **`docs/ru/MATSim_basic_concepts_guide.pdf`**

### DOCX

- Генерация из Markdown (например, через `md2docx-python` или вручную). Исходники — те же `.md`; пути к картинкам в отчёте заданы относительно `docs/ru/progress/` (папка `img/`).
- Результаты при необходимости сохраняют рядом с отчётами: `10_final_report_shamalgan.docx`, `MATSim_basic_concepts_guide.docx`.

### Презентация PowerPoint

- **Скрипт:** `tools/build_shamalgan_report_presentation.py`
- **Выходной файл:** **`docs/ru/progress/10_final_report_shamalgan.pptx`** (генерируется по итоговому отчёту).
- **Зависимости:** `pip install python-pptx`
- **Запуск (из корня проекта):**  
  `python tools/build_shamalgan_report_presentation.py`
